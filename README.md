### 🌌 Constelación de Proyectos

* 🚀 **Cloud Financial Agent:**
  * Agente financiero autónomo y *self-hosted* diseñado para la gestión presupuestal 50/30/20.
  * **Características:** Ingesta multimodal de gastos (texto, voz, fotos de recibos), lectura automatizada de correos bancarios vía IMAP, reglas antiduplicidad y generación de gráficos.
  * **Stack Tecnológico:** Python, Google Gemini API, Telegram Bot, SQLite, Grafana, Docker Compose y despliegue en TrueNAS.
* 🛰️ **Servidor Privado (Homelab):** Infraestructura de nube personal desplegada en TrueNAS, orquestando servicios (Immich, OpenGym) con Docker Compose y redes seguras P2P con Tailscale.[cite: 1]
* 📱 **Aplicaciones Multiplataforma:** Creación de interfaces móviles modulares en Flutter y Dart, acelerando el desarrollo con herramientas como Antigravity CLI e IA.[cite: 1]
* ✨ **Plataforma Web Integral de Gestión:** Implementación de control de acceso basado en roles (Spatie Permissions) e interfaces reactivas usando el ecosistema de Laravel.[cite: 1]
